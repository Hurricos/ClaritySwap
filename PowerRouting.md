# From, to the battery
We can use two of the existing phase cables for this. Alternatively, we can scrap the phase cables and use a custom harness.

The Clarity and Insight battery power cable glands into the PCU are different -- the Clarity's is more robust than the Insight one, and it uses a type of connector that I believe can be more easily rewired. This would be useful if we end up reusing the phase cables wholesale for battery current.
