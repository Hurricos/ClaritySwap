# TL;DR: ClaritySwap
Notes pertinent to swapping a Honda iMMD transaxle and inverter (PCU) into a
Gen1 Honda Insight.

Work in progress. Well, it was once.

Only two iMMD donor vehicles are considered, though this repo contains details
about a swath of related vehicles:
- The 2018-2021 Honda Clarity
- The 2019-2022 Honda Insight

## Inventory
- `Mechanicals/`: axles, engine-transmission fit, pedal mount
- `Electricals/Inverter/`: Clarity PCU teardown and papers
- `TODO.md`, `Cooling.md`, `PowerRouting.md`, `Weight.md`: open questions

## Author background
The primary author (hurricos) has never successfully transplanted ("swapped")
non-trivially-compatible systems from one car to another, though he has
experience with cars (swapping engines, brake lines, using vendor programming
tools like TechStream and Honda HDS), and varying degrees of familiarity with
most technologies used in the applicable donor vehicles (CAN, high-voltage
batteries, electric motors and inverters).
